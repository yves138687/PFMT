# Personal Knowledge System 前端页面及交互说明文档

## 1. 文档说明

### 1.1 目的
本文档用于定义 `Personal Knowledge System` 的前端页面结构、布局规则、组件组成、交互行为和状态表现，作为后续 AI 生成前端页面与人工开发实现的统一依据。

### 1.2 适用范围

- PC Web 为主
- 兼容平板与移动端缩放展示
- 当前阶段优先单用户场景
- 当前阶段优先文件管理、加密文件展示、受控 AI 交互

### 1.3 设计原则

1. 信息架构清晰，优先保证“路径 -> 文件 -> 文件内容”的主链路顺畅
2. 风格参考 `Wiki.js` 一类知识管理后台，但保持更轻、更现代
3. 左侧固定树结构，右侧内容区承担主要业务
4. 所有 AI 能力必须明确显示“可读取范围”
5. 默认状态下不泄露隐藏内容是否存在，只有用户主动开启“显示隐藏内容”后才展示相关状态提示
6. 文件列表区域布局优先参考 Windows 资源管理器，支持图标视图与列表视图

## 2. 整体视觉风格

### 2.1 风格方向

参考你给出的截图，整体采用：

- 浅色背景
- 顶部细导航栏
- 左侧固定侧边树
- 右侧大面积内容工作区
- 卡片 + 表格混合布局
- 操作按钮轻量化、蓝色主按钮为主

说明：

- 截图主要用于参考“后台整体框架风格”
- 文件列表区域不完全照搬截图
- 文件列表区域优先参考 Windows 文件管理器的布局逻辑

### 2.2 视觉关键词

- 干净
- 克制
- 信息密度中等
- 以可读性优先
- 偏知识管理后台，而非营销页面

### 2.3 颜色建议

- 主色：偏蓝色系，例如 `#3B82F6`
- 辅助色：浅灰、灰蓝
- 成功色：绿色
- 风险色：红色
- 警示色：橙色
- 背景：`#F5F7FA` / `#F8FAFC`
- 卡片背景：白色

### 2.4 圆角与阴影

- 卡片使用中等圆角
- 面板阴影轻量
- 不做厚重浮层风格

### 2.5 字体与排版

- 中文优先使用系统无衬线字体
- 标题层级清楚
- 表格与文件信息优先可读性

## 3. 全局布局结构

### 3.1 PC 端整体布局

页面采用三段式结构：

1. 顶部导航栏
2. 左侧侧边栏
3. 右侧主内容区

建议结构：

```text
┌──────────────────────────────────────────────┐
│ 顶部导航栏                                   │
├───────────────┬──────────────────────────────┤
│ 左侧树状侧边栏 │ 右侧主内容区                 │
│               │                              │
│               │ 首页 / 列表 / 详情 / 编辑 / AI │
└───────────────┴──────────────────────────────┘
```

### 3.2 宽度建议

- 顶部导航栏：全宽
- 左侧侧边栏：`260px ~ 320px`
- 右侧主内容区：自适应剩余宽度

### 3.3 响应式策略

- 平板：左侧栏可折叠
- 手机：左侧树改为抽屉
- 移动端右侧 AI 面板改为抽屉或底部弹层

## 4. 顶部导航栏

### 4.1 页面定位
顶部导航栏是全局导航、用户信息入口和系统级操作入口，风格参考 `Wiki.js` 的轻量顶部条。

### 4.2 布局结构

从左到右建议为：

1. 菜单折叠按钮
2. 产品 Logo / 产品名
3. 当前页面面包屑
4. 全局搜索入口
5. 全局快速操作入口
6. 用户信息区

### 4.3 展示内容

- 左侧汉堡菜单图标
- 产品名称，例如 `Personal Knowledge System`
- 当前路径，例如 `首页 / 项目 / 技术方案`
- 搜索框或搜索按钮
- 用户头像 / 用户名
- 系统设置入口
- 其他功能下拉菜单

### 4.4 其他功能建议包含

- 新建目录
- 上传文件
- 显示隐藏内容开关
- AI 配置
- 备份中心
- 系统设置
- 登出

### 4.5 交互说明

- 点击左上角菜单图标：展开/折叠左侧边栏
- 点击面包屑：跳转到对应层级
- 点击用户区：展开用户菜单
- 点击显示隐藏内容：弹出时效选择

## 5. 登录页（首页）

### 5.1 页面定位
登录页是系统入口页，也是未登录状态下的首页。

### 5.2 布局建议

采用左右分栏或居中卡片布局：

- 左侧：产品介绍 / 简短视觉区
- 右侧：登录表单

在资源有限和后台产品定位下，也可以采用更简单的居中卡片布局。

### 5.3 页面组成

- 产品 Logo
- 产品名称
- 简短说明文案
- 用户名输入框
- 密码输入框
- 登录按钮
- 登录错误提示
- 系统版本号

### 5.4 交互说明

- 用户名、密码必填
- 登录失败时显示错误提示
- 登录成功后跳转到“根节点首页”
- 已登录访问登录页时自动跳转首页

### 5.5 状态说明

- 默认状态
- 输入中状态
- 登录中状态
- 登录失败状态

## 6. 登录后根节点首页

### 6.1 页面定位
这是登录后默认进入的工作台首页，用于给用户提供整个知识库的总体概览。

### 6.2 布局结构

建议分为 4 个区域：

1. 欢迎区
2. 统计卡片区
3. 最近访问区
4. 快捷入口区

### 6.3 统计卡片建议

至少包含以下卡片：

- 文件总数
- 目录总数
- 占用存储总量
- 图片数量
- 视频数量
- PDF 数量
- 文本文档数量

说明：

- 首页统计卡片默认不展示任何“隐藏文件数量”“隐藏目录数量”“私密内容数量”之类会暴露隐藏内容存在感的信息
- 若后续需要隐藏内容统计，只能在用户主动进入系统设置或安全页，并明确授权查看后展示

### 6.4 统计卡片展示方式

每个卡片包含：

- 图标
- 指标名称
- 数值
- 简短说明

### 6.5 最近访问区

展示最近访问文件列表，字段包括：

- 文件名
- 所属路径
- 文件类型
- 最近访问时间

点击后直接进入文件详情页。

补充约束：

- 默认最近访问区不展示隐藏文件
- 只有在用户主动开启“显示隐藏内容”且当前会话授权有效时，才允许显示隐藏文件访问记录

### 6.6 快捷入口区

建议提供：

- 新建目录
- 上传文件
- 打开备份中心
- 打开系统设置
- 打开 AI 配置

---

## 7. 左侧侧边栏（树状结构）

### 7.1 页面定位
左侧侧边栏用于展示知识库目录树，是整个系统的主导航入口。

### 7.2 布局组成

- 顶部搜索框
- 目录树区域
- 快速操作区

### 7.3 目录树展示规则

- 支持展开/折叠
- 支持普通路径与私密路径
- 支持当前选中高亮

补充约束：

- 默认不展示隐藏目录
- 默认不展示“这里有隐藏目录”的任何占位提示
- 只有在用户主动开启“显示隐藏内容”后，才显示隐藏目录及其状态标识

### 7.4 节点类型

- 根节点
- 普通目录
- 私密路径目录
- 文件节点（如需要树内直接显示文件）

补充说明：

- “隐藏目录”不是默认可见节点类型
- 仅在授权显示隐藏内容时，隐藏目录才进入树结构渲染

### 7.5 每个目录节点支持操作

- 新建子目录
- 上传文件
- 重命名
- 设为隐藏
- 取消隐藏
- 删除

### 7.6 视觉交互建议

- 选中节点使用浅蓝高亮
- 私密路径可加锁图标
- 展开箭头清晰可点击

补充说明：

- 眼睛关闭图标、隐藏标记等只在“显示隐藏内容”开启后出现

### 7.7 搜索框作用

用于在目录树中快速筛选路径名称，不直接替代全局元数据搜索。

## 8. 目录页：某个目录下的文件列表页

### 8.1 页面定位
当用户点击某个目录后，右侧主内容区展示该目录下的文件列表和目录级操作。

### 8.2 页面结构

从上到下建议为：

1. 目录标题区
2. 工具栏
3. 筛选栏
4. 文件列表区
5. 分页区

### 8.3 文件列表区布局原则

文件列表区域整体参考 Windows 文件管理器，支持两种主视图：

1. 图标卡片视图
2. 列表表格视图

用户可在工具栏中切换视图模式。

### 8.4 标题区内容

- 当前目录名称
- 路径面包屑
- 目录简介或说明（可选）

### 8.5 工具栏建议

- 上传文件
- 新建目录
- 新建文档
- 批量操作
- 显示隐藏内容
- 视图切换：图标 / 列表
- 排序方式：名称 / 时间 / 大小 / 类型

### 8.6 筛选栏建议

- 文件名搜索
- 文件类型筛选
- 标签筛选
- 创建时间范围
- 更新时间范围

补充说明：

- 默认不显示“是否隐藏”筛选
- 仅在用户已开启“显示隐藏内容”时，才出现隐藏相关筛选项

### 8.7 列表视图字段

至少展示以下信息：

- 真实文件名
- 文件类型
- 文件大小
- 创建时间
- 更新时间
- 标签
- 所属路径
- 可执行操作

补充说明：

- 默认列表字段不展示“是否隐藏”
- 当用户开启“显示隐藏内容”后，可增加一列“状态”或“可见性”，用于区分正常 / 隐藏

### 8.8 图标卡片视图说明

图标卡片视图更接近 Windows 图标模式，适合图片、视频、PDF 和混合文件浏览场景。

每个卡片建议展示：

- 文件图标或缩略图
- 文件名
- 文件类型
- 文件大小
- 更新时间

补充说明：

- 默认卡片不展示隐藏状态标识
- 只有在显示隐藏内容后，卡片角标或状态图标才可出现

卡片交互建议：

- 单击选中
- 双击打开
- 右键弹出文件操作菜单

### 8.9 列表视图说明

列表视图更适合信息密度高和批量管理场景。

优点：

- 信息密度高
- 文件字段多
- 操作入口更稳定

建议：

- 默认按名称排序
- 支持列头排序
- 支持复选框批量选择

### 8.10 每行或每卡片操作建议

- 查看
- 编辑
- 下载
- 重命名
- 移动
- 设为隐藏 / 取消隐藏
- 删除
- 打开后使用 AI

### 8.11 选中态与右键菜单

参考 Windows 文件管理器交互，建议支持：

- 单选
- 多选
- Shift 连续选择
- Ctrl 多选
- 右键菜单

右键菜单建议包含：

- 打开
- 在新标签打开
- 下载
- 重命名
- 移动
- 隐藏 / 取消隐藏
- 删除
- 打开后使用 AI

### 8.12 空状态

当目录下没有文件时，展示：

- 空状态插图或简洁图标
- 文案提示
- 上传文件按钮
- 新建目录按钮

## 9. 文件详情页

### 9.1 页面定位
当用户点击具体文件后，进入文件详情页。该页面根据文件类型提供不同的操作与展示方式。

文件打开交互建议参考 Windows：

- 单击文件仅选中
- 双击文件打开详情页
- Enter 键打开当前选中文件
- 右键菜单提供常用操作

### 9.2 页面通用结构

从上到下建议为：

1. 文件标题区
2. 文件元信息区
3. 文件内容展示区
4. 操作栏
5. AI 面板或 AI 入口

### 9.3 标题区内容

- 文件名
- 文件类型图标
- 所属路径面包屑

补充说明：

- 文件详情页仅在当前文件本身已被用户授权查看且属于隐藏文件时，才展示隐藏状态标记

### 9.4 元信息区

- 文件大小
- 创建时间
- 更新时间
- 标签
- 摘要
- 文件状态

### 9.5 操作栏建议

- 下载
- 重命名
- 移动
- 删除
- 设为隐藏 / 取消隐藏
- AI 总结当前文件

补充说明：

- 不提供独立的“发送给 AI”按钮

## 11. AI 面板设计

### 11.1 页面定位
AI 面板是当前页面的辅助工作区，不应喧宾夺主，但要随时可用。

### 11.2 PC 端布局建议

建议放置在右侧抽屉式侧栏或右侧固定面板。

### 11.3 面板内容

- 当前 AI 可读取范围提示
- 输入框
- `@文件` 引用能力
- 常用操作按钮
- 聊天记录区

### 11.4 当前 AI 可读取范围提示

必须明确展示，例如：

- 当前打开文档：`技术方案.md`
- 当前选中段落：`第 3 段`
- 已引用文件：`@需求说明书.md`

### 11.5 常用快捷操作

- 总结当前文件
- 润色选中内容
- 翻译选中内容
- 扩写选中内容
- 基于当前文档问答

### 11.6 交互边界

- AI 不允许全局搜索知识库
- AI 不能隐式读取其他未指定文件
- 若涉及隐藏内容，必须有明确提示

补充说明：

- 若当前文件或 `@文件` 属于隐藏内容，AI 面板应明确提示“本次将读取隐藏内容”
- 若未开启隐藏内容展示，隐藏文件不应出现在 `@文件` 自动补全候选中

### 14.1 页面定位

## 18. 建议给 AI 生成前端时的实现提示

后续如果要让 AI 直接生成前端页面，建议明确给出以下约束：

- 使用 `Vue 3 + TypeScript + Element Plus + Pinia`
- 页面风格参考轻量知识管理后台
- 布局采用“顶部导航 + 左侧树 + 右侧内容区”
- 所有页面都要有加载、空状态、错误状态
- 文件列表区域参考 Windows 文件管理器
- 支持图标卡片视图与列表视图切换
- 首页优先用统计卡片 + 最近访问
- AI 面板必须显示“可读取范围”
- 默认不泄露隐藏内容存在感
- 隐藏标识仅在用户主动开启“显示隐藏内容”后可见
